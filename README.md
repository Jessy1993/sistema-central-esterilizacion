# Sistema de Gestión para una Central de Esterilización

Proyecto académico desarrollado para la asignatura Ingeniería de Software.

## Módulo implementado

Gestión del inventario de instrumental médico.

## Objetivo

Registrar el ingreso y salida del instrumental, controlar su stock y mantener la trazabilidad durante los procesos de esterilización.

## Tecnologías

- Python
- Pytest
- GitHub
- GitHub Actions
